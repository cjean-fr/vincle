# Host logos

Monochrome brand marks from [Simple Icons](https://github.com/simple-icons/simple-icons) (icons/*.svg, CC0 1.0 for the files), drawn in the text colour by a CSS mask. The marks are trademarks of their owners and are shown only to name the host.

- Vercel: vercel.svg
- Cloudflare: cloudflare.svg
- Netlify: netlify.svg
- GitHub Pages: github-pages.svg (the GitHub mark)
- nginx: nginx.svg

Tabler Icons has marks for Vercel, Cloudflare and GitHub only. Mixing its outlines with the filled marks of the other hosts looked uneven, so this row uses Simple Icons throughout.
