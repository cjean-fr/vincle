# Installation

`@vincle/core` has zero runtime dependencies. Install it, then configure
TypeScript.

## Install

In an existing project, one with a `package.json`.

```bash tab="npm" sync="pkg-manager"
npm install @vincle/core
```

```bash tab="pnpm" sync="pkg-manager"
pnpm add @vincle/core
```

```bash tab="bun" sync="pkg-manager"
bun add @vincle/core
```

```bash tab="agent" sync="pkg-manager"
npx skills add cjean-fr/vincle
```

With **agent**, the command adds the Vincle skill to the project. The skill sends
your agent to these docs: ask it to set up Vincle, on Bun or Node.js, and it
installs and configures the package, then runs a hello world and the type check.

## Node setup

Node only. The examples use top-level await, so the project must be an ES
module. Node does not run `.tsx` files: `tsx` runs them, `typescript` checks
types. To type Node APIs (`node:fs`, `process`), add `"types": ["node"]` to
the `compilerOptions` of the `tsconfig.json` below.

```bash tab="npm" sync="pkg-manager"
npm pkg set type=module
npm install -D typescript tsx @types/node
```

```bash tab="pnpm" sync="pkg-manager"
pnpm pkg set type=module
pnpm add -D typescript tsx @types/node
```

## TypeScript configuration

The same `tsconfig.json` for npm, pnpm and Bun. `jsxImportSource` lets JSX files
work without an import.

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "es2022",
    "module": "preserve",
    "moduleResolution": "bundler",
    "strict": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "jsxImportSource": "@vincle/core"
  }
}
```

Attributes are typed per element (`src` on `<img>`, `href` on `<a>`), with
nothing extra to install: see [JSX types](/api/core/jsx-types).

## Run a file

Save the [hello world](/guide/getting-started/first-render#hello-world) as
`index.tsx`, add `console.log(html)` at the end, then run it.

```bash tab="npm" sync="pkg-manager"
npx tsx index.tsx
npx tsc # type check
```

```bash tab="pnpm" sync="pkg-manager"
pnpm exec tsx index.tsx
pnpm exec tsc # type check
```

```bash tab="bun" sync="pkg-manager"
bun index.tsx
bun check # type check, built into Bun
```
