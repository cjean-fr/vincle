        <span class="docs-example-language">TypeScript</span>

      ```tsx {1,8} title="hello.tsx"
      import { renderToString } from "@vincle/core";

      function App({ name }: { name: string }) {
        return <h1>Hello, {name}!</h1>;
      }

      const page = <App name="world" />;
      const html = await renderToString(page);
      ```

    <div class="docs-path-grid">
      <article class="docs-path-card">
        <p class="docs-path-kicker">In your server</p>
        <h3>Return the HTML from a route</h3>
        <p>Keep your router, your middleware and your handler. Render the view and send the string.</p>
        ```tsx title="server.ts"
        app.get("/", async (c) => {
          const html = await renderToString(<Home user={user} />);
          return c.html(html);
        });
        ```
        <a class="docs-text-link" href="/guide/views">Connect a view to your server</a>
      </article>
      <article class="docs-path-card">
        <p class="docs-path-kicker">At build time <span class="docs-badge">beta</span></p>
        <h3>Write a whole site to files</h3>
        <p>@vincle/ssg renders a directory of pages, with layouts, Markdown and assets, to static files.</p>
        ```html title="dist/index.html"
        <main>
          <h1>My site</h1>
        ```
