      ```tsx {1,8} title="hello.tsx"
      const html = await renderToString(page);
      ```

        ```tsx title="src/pages/index.tsx"
        export const meta = { title: "Home" };

        export default async function Home() {
          const posts = await listPosts();
          return (
            <main>
              <h1>My site</h1>
              <ul>
                {posts.map((post) => (
                  <li>{post.title}</li>
                ))}
              </ul>
            </main>
          );
        }
        ```

  <section class="docs-home-section docs-independent" aria-labelledby="independent-title">
    <div class="docs-section-heading">
      <h2 id="independent-title">Independent by design.</h2>
      <p>One maintainer, a scope that stays small, and checks you can read for yourself.</p>
    </div>
    <div class="docs-use-cases">
      <article>
        <h3>Built for a simpler need</h3>
        <p>
          Vincle renders HTML on the server and stops there. Its scope is deliberate: views render to HTML
          without a virtual DOM, hydration or a reconciler.
        </p>
        <a class="docs-text-link" href="/guide/comparison">
          {"Read the comparison"}
        </a>
      </article>
      <article>
        <h3>Feedback reaches the person who decides</h3>
        <p>
          Issues and proposals are read by the maintainer who can act on them. A well-argued proposal can ship in
          the next release, as long as it fits the project's scope.
        </p>
        <a class="docs-text-link" href="https://github.com/cjean-fr/vincle/issues">
          {"Open an issue"}
        </a>
      </article>
      <article>
        <h3>Public checks, with their limits stated</h3>
        <p>
          Tests, differential fuzzers, mutation testing and comparative benchmarks are public, method included.
          They support specific claims; they are not an external audit.
        </p>
        <a class="docs-text-link" href="https://github.com/cjean-fr/vincle/actions">
          {"See the checks"}
        </a>
      </article>
      <article>
        <h3>A focused tool you adopt view by view</h3>
        <p>
          An MIT-licensed library you adopt view by view, keeping your server and routing. Rendering HTML
          imposes no client runtime; streaming can add a patch script, depending on the adapter. Its APIs are
          still a dependency, and porting views elsewhere is real work.
        </p>
        <a class="docs-text-link" href="https://github.com/cjean-fr/vincle/blob/main/LICENSE">
          {"Read the license"}
        </a>
      </article>
