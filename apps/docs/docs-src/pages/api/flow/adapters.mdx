# Adapters

An adapter controls how placeholders and patches are encoded in the HTML shell. Import from `@vincle/flow/adapters`.

<CodeExample src="flow/adapters.ts" />

## Built-in adapters

| Adapter              | Target                                             | Merge support                           | Size           |
| -------------------- | -------------------------------------------------- | --------------------------------------- | -------------- |
| `NativeAdapter`      | Inline polyfill via `<template for>`               | replace, append, prepend, before, after | ~550B polyfill |
| `TurboAdapter`       | Turbo Streams (`<turbo-frame>` / `<turbo-stream>`) | replace, append, prepend, before, after | —              |
| `HtmxAdapter`        | HTMX (`hx-swap-oob`)                               | replace, append, prepend, before, after | —              |
| `WebPlatformAdapter` | WICG declarative partial updates                   | replace only                            | —              |
| `EsiAdapter`         | CDN edge composition via `esi:include`             | replace                                 | —              |

## Usage

Pass an adapter to `renderToStream` or `renderToStatic`. It is a required
second argument — there is no implicit default:

```tsx
import { renderToStream } from "@vincle/flow";
import { NativeAdapter } from "@vincle/flow/adapters";

const stream = renderToStream(() => <Page />, NativeAdapter);
```

## Merge types

| `merge`     | Effect                                    |
| ----------- | ----------------------------------------- |
| `"replace"` | Target element is replaced (default)      |
| `"append"`  | Content inserted as last child of target  |
| `"prepend"` | Content inserted as first child of target |
| `"before"`  | Content inserted as previous sibling      |
| `"after"`   | Content inserted as next sibling          |

Not every adapter supports all merge types — an unsupported merge is rejected at registration with a clear error.
