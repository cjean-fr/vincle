# Components

Components for deferring content in the HTML shell. Imported from `@vincle/flow`.

## Template

Registers content to render later, in place of a placeholder. Unified —
handles both sync and lazy content. `Template` renders its own placeholder —
`fallback` is its content — so no `Slot` needs to exist first:

- **Sync** (plain JSX `children`) → content registered; placeholder rendered, `fallback` is its content
- **Lazy** (factory `children`) → content deferred; placeholder rendered, `fallback` is its content

<CodeExample src="flow/defer-signal.tsx" />

This is the common case: placeholder and deferred content declared together,
in one place, nothing else required. Reach for `Slot` only when the
placeholder's position needs to be declared somewhere `Template` can't reach
directly — see below.

**Props:**

| Prop       | Type                                                                                                                                                     | Default     | Description                                                  |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------ |
| `target`   | `string`                                                                                                                                                 | —           | Id the placeholder (and its later patch) is registered under |
| `fallback` | `VNode`                                                                                                                                                  | —           | Content rendered in the placeholder                          |
| `children` | `JSX.Element \| string \| ((signal: AbortSignal) => JSX.Element) \| AsyncIterable<JSX.Element> \| ((signal: AbortSignal) => AsyncIterable<JSX.Element>)` | —           | Content — plain JSX, a factory, or an async iterable         |
| `merge`    | `"replace" \| "append" \| "prepend" \| "before" \| "after"`                                                                                              | `"replace"` | How content applies to the target                            |
| `timeout`  | `number`                                                                                                                                                 | —           | Per-fragment render timeout in ms                            |
| `onError`  | `(error: unknown, info: FlowErrorInfo) => JSX.Element \| void`                                                                                           | —           | Per-fragment error handler                                   |

## Slot

Declares a named insertion point that stands in for a `Template` rendered
elsewhere in the tree — typically a layout reserving a spot that a
page-specific component fills later, by matching `target` to `name`. Its
children render immediately as placeholder content, visible until the
matching `Template` patches them.

<CodeExample src="flow/fill-signal.tsx" />

Every adapter renders a placeholder as an element (or marker) carrying that
one id, and every adapter's patch resolves to the _first_ match in the
document — the same rule HTML `id` uniqueness and `getElementById` already
impose. So when pairing `Slot` with `Template`, `Slot` must come first, and
`Template` should skip its own `fallback` — passing one there just renders a
second, dead placeholder with the same id right next to `Slot`'s live one.

**Props:**

| Prop       | Type     | Default | Description                                        |
| ---------- | -------- | ------- | -------------------------------------------------- |
| `name`     | `string` | —       | Fragment id, required                              |
| `children` | `VNode`  | —       | Fallback content rendered immediately in the shell |

## Include

Browser fetches a fragment from a URL after the shell lands. No server-push required — works with any static file server.

**Props:**

| Prop       | Type     | Default | Description                            |
| ---------- | -------- | ------- | -------------------------------------- |
| `src`      | `string` | —       | URL of the fragment HTML file to fetch |
| `fallback` | `VNode`  | —       | Placeholder shown while fetching       |

## Style / Script — asset emission

`<Style>` and `<Script>` emit their tag at their own position in the tree, once per `name` — first occurrence wins. Later occurrences return `null`, so a page can declare its own CSS/JS without a separate asset-resolution pass.

```tsx
import { Style, Script } from "@vincle/flow/components";

const Page = () => (
  <>
    <Style name="page.css" media="screen">
      {`.hero { color: red; }`}
    </Style>
    <Script name="page.js" defer src="/page.js" />
    <main>…</main>
  </>
);
```

**Style props:**

| Prop       | Type                                  | Default | Description                                       |
| ---------- | ------------------------------------- | ------- | ------------------------------------------------- |
| `name`     | `string`                              | —       | Asset id, required, dedup key                     |
| `media`    | `string`                              | —       | `media` attribute                                 |
| `children` | `string \| (() => Awaitable<string>)` | —       | CSS text, evaluated only if this occurrence emits |

**Script props:**

| Prop       | Type                                  | Default | Description                                        |
| ---------- | ------------------------------------- | ------- | -------------------------------------------------- |
| `name`     | `string`                              | —       | Asset id, required, dedup key                      |
| `src`      | `string`                              | —       | `src` attribute                                    |
| `module`   | `boolean`                             | `false` | Sets `type="module"`                               |
| `defer`    | `boolean`                             | `false` | Sets the `defer` attribute                         |
| `children` | `string \| (() => Awaitable<string>)` | —       | Inline JS, evaluated only if this occurrence emits |

In static generation, standalone fragment files (`emitFragments`) suppress asset emission — the shell that includes them already carries the assets, so fragments are emitted without a duplicate `<style>`/`<script>` tag.

## Content forms

`Template` accepts children in either form:

| Children                     | Behaviour                                                          |
| ---------------------------- | ------------------------------------------------------------------ |
| Plain JSX                    | Deferred automatically — no thunk needed                           |
| `(signal: AbortSignal) => …` | **Cancellable** — receives `AbortSignal` (request + timeout abort) |

**Return types (for both forms):**

| Return type                  | Behaviour                                            |
| ---------------------------- | ---------------------------------------------------- |
| A renderable JSX node        | One-shot patch — renders once and resolves           |
| `Promise<JSX.Element>`       | Resolves asynchronously, then patches in             |
| `AsyncIterable<JSX.Element>` | A stream — one patch per item, as each item resolves |
