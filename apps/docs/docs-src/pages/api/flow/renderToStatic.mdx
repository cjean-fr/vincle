# renderToStatic

Build HTML files at compile time. Gives you a context to render all your pages, then emit fragment files if any page uses lazy `Template`.

## Signature

```tsx
import { renderToStatic } from "@vincle/flow";

// Pure static — no adapter, no emitFragments
function renderToStatic<T>(fn: (ctx: PureStaticContext) => T): Promise<T>;

// With deferred fragments — adapter required
function renderToStatic<T>(fn: (ctx: StaticContext) => T, options: StaticOptions): Promise<T>;
```

## Options

| Option         | Type                     | Default                              | Description                              |
| -------------- | ------------------------ | ------------------------------------ | ---------------------------------------- |
| `adapter`      | `Adapter`                | — (required)                         | Wire-format adapter for fragment framing |
| `generatePath` | `(id: string) => string` | ``(id) => `/fragments/${id}.html` `` | URL path for each fragment               |

**Options are validated up front** — before a single page renders. A missing
or malformed `adapter`, or a non-function `generatePath`, fails at the call
with a message prefixed `[vincle/flow]` that names the option, the offending
value, and the fix. See [Error handling](/api/core/error-handling).

## Contexts

### PureStaticContext

| Method       | Signature                                      | Description                                   |
| ------------ | ---------------------------------------------- | --------------------------------------------- |
| `renderPage` | `(node: () => JSX.Element) => Promise<string>` | Renders a page returning the full HTML string |

### StaticContext

| Method          | Signature                                                                                   | Description                                              |
| --------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `renderPage`    | `(page: () => VNode) => Promise<string>`                                                    | Renders a page returning the full HTML string            |
| `emitFragments` | `(emit: (id: string, url: string, html: string) => void \| Promise<void>) => Promise<void>` | Materializes deferred fragments, passes each to callback |

## Pure static

No lazy `Template` in your pages? Call `renderToStatic` without options (just the handler). The handler receives a `PureStaticContext` — `emitFragments` does not exist, so the type system prevents accidental use.

## With deferred fragments

Pass `{ adapter }` as the second argument. The handler receives a `StaticContext` with `emitFragments`. Each deferred fragment is rendered and passed to your callback.

The same path must be declared in the page's `Include src` so the browser knows where to find each fragment.
