# Installation

Installez `@vincle/core` dans votre application. Il fonctionne avec Bun, Node.js et Deno.

## Gestionnaire de paquets

Choisissez votre gestionnaire de paquets : Bun, pnpm ou npm. Le package n’a aucune dépendance d’exécution.

```bash tab="npm" sync="pkg-manager"
npm install @vincle/core
```

```bash tab="pnpm" sync="pkg-manager"
pnpm add @vincle/core
```

```bash tab="bun" sync="pkg-manager"
bun add @vincle/core
```

## Configuration TypeScript

Activez `react-jsx` et définissez `jsxImportSource` sur `@vincle/core`. Les types JSX proviennent alors de Vincle. Avec Deno, utilisez sa configuration native.

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@vincle/core"
  }
}
```
