# Components

Components are plain functions that return JSX. No classes, no hooks, no lifecycle: just props in, string out.

## Basics

A component receives props as its first argument and returns JSX:

```tsx
import { renderToString } from "@vincle/core";

function Greeting({ name }: { name: string }) {
  return (
    <p>
      Hello, <strong>{name}</strong>!
    </p>
  );
}

const html = await renderToString(<Greeting name="Alice" />);
```

```html
<p>Hello, <strong>Alice</strong>!</p>
```

## Typed props

Props are typed with standard TypeScript interfaces:

```tsx
interface CardProps {
  title: string;
  children: VNode;
}

function Card({ title, children }: CardProps) {
  return (
    <div class="card">
      <h2>{title}</h2>
      {children}
    </div>
  );
}
```

## Composition

Components compose naturally: pass one component's output as another's children:

```tsx
import { renderToString, type JSX } from "@vincle/core";

function Layout({ title, children }: { title: string; children: JSX.Element | JSX.Element[] }) {
  return (
    <html lang="en">
      <head>
        <title>{title}</title>
      </head>
      <body>{children}</body>
    </html>
  );
}

const html = await renderToString(
  <Layout title="My page">
    <h1>Welcome</h1>
    <p>This is a page rendered with Vincle.</p>
  </Layout>,
);
```

## Async components

Any component can be `async`. The whole tree is awaited by `renderToString`:

```tsx
async function Profile({ id }: { id: string }) {
  const user = await db.users.find(id);
  return (
    <div class="profile">
      <h1>{user.name}</h1>
      <p>{user.bio}</p>
    </div>
  );
}
```

Sibling async branches run in document order, one at a time: `renderToString` resolves only when every branch finishes.

## What you don't need

- **State**: there is no re-rendering. State lives outside the render (database, request context).
- **Effects**: no client lifecycle. Render once, produce a string, done.
- **Client context updates**: a React-style `Context.Provider` supplies values during
  server rendering; Vincle does not re-render in the browser.
- **`React.memo`**: every render is a fresh call. Memoization is meaningless.
