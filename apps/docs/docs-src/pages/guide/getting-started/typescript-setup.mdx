# TypeScript setup

Vincle uses standard JSX — the same transform React, Preact, and Solid use.
Configure it once in your `tsconfig.json` (or build tool) and every `.tsx`
file picks it up.

## tsconfig.json

```json
//tsconfig.json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@vincle/core"
  }
}
```

With `jsxImportSource` set, your JSX files never need an explicit import —
the compiler injects the runtime calls for you.

## Deno

`@vincle/core` works with Deno's built-in JSX transform. Configure the import
source in `deno.json` so you don't need explicit imports in every file:

```json title="deno.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "npm:@vincle/core"
  },
  "imports": {
    "@vincle/core": "npm:@vincle/core"
  }
}
```

Deno also supports `jsx: "precompile"` — Deno's own compile-time JSX transform.
When enabled, Vincle exports the `jsxTemplate` and `jsxAttr`
helpers it needs. Note that `dangerouslySetInnerHTML` is **not dropped** in
precompile mode: the transform leaves it to the runtime, where the classic
JSX runtime's `jsx()` handles it. On the precompile path, prefer `{raw(html)}`
as a child.

## Vite / esbuild

Set the import source in your build config instead of `tsconfig.json`:

```ts
// vite.config.ts
export default defineConfig({
  esbuild: { jsx: "automatic", jsxImportSource: "@vincle/core" },
});
```

Vite reads either `tsconfig.json` or its own `esbuild` option — they are
equivalent.

### Precompile plugin (recommended for production)

For faster rendering and smaller bundles, add the precompile plugin. It
rewrites JSX into tagged template literals — less allocations, less GC
pressure, faster rendering:

```ts
import precompile from "@vincle/precompile/vite";

export default defineConfig({
  esbuild: { jsx: "automatic", jsxImportSource: "@vincle/core" },
  plugins: [precompile()],
});
```

**Static attribute sanitization is enabled by default** — literal
`href="javascript:…"` and unsafe CSS are blocked at build time, before
they ever reach the bundle. See [Precompile transform → Build-time
sanitization](/integration/precompile#build-time-sanitization).

## Attribute types

Every HTML and SVG element is typed per element — `src` on `<img>`, `href` on
`<a>`, `colSpan` on `<td>`. The types ship inside `@vincle/core`, so a typo is
a compile error: `<div clas="card">` never passes silently.
