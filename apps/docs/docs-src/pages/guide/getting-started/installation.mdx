# Installation

`@vincle/core` has zero runtime dependencies. Install it and configure
TypeScript. That's all.

## Package manager

```bash tab="npm" sync="pkg-manager"
npm install @vincle/core
```

```bash tab="bun" sync="pkg-manager"
bun add @vincle/core
```

## TypeScript configuration

Set `jsxImportSource` in your `tsconfig.json` so JSX files need no import:

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@vincle/core"
  }
}
```

## What you get

### Runtime

| Export                            | Purpose                                    |
| --------------------------------- | ------------------------------------------ |
| `renderToString(node)`            | Renders a JSX tree to an HTML string       |
| `raw(str)`                        | Marks a trusted HTML string (no escaping)  |
| `rawUrl(url)`                     | Marks a trusted URL scheme (still escaped) |
| `Fragment`                        | Standard JSX fragment (`<>…</>`)           |
| `createContext`, `useContext`     | Share a value with a Provider subtree      |
| `Scope`                           | Per-execution state and isolated scopes    |
| `jsx-runtime` / `jsx-dev-runtime` | JSX transform entry points (auto-wired)    |

### Types

| Export          | Purpose                                      |
| --------------- | -------------------------------------------- |
| `Renderable`    | Everything the renderers can render          |
| `VNode`         | What `jsx()` produces (a type only)          |
| `RawString`     | Branded type for pre-escaped HTML            |
| `RawUrl`        | Branded type for a URL with a trusted scheme |
| `CSSProperties` | What a `style` object accepts                |
| `Awaitable<T>`  | `T` or a promise of `T`                      |
| `ClassValue`    | What a `class` attribute accepts             |
| `JSX`           | The JSX namespace                            |
| `Context<T>`    | Tree context with a typed Provider           |
| `ScopeKey<T>`   | Branded execution-context key type           |
| `ScopeMap`      | Execution-context map type                   |

Attributes are typed per element (`src` on `<img>`, `href` on `<a>`), with
nothing extra to install: see [JSX types](/api/core/jsx-types). Everything else
is internal.
